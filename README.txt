
WEEK 2 - DEBUGGING AND TROUBLESHOOTING PYTHON APPLICATIONS

Project Name: Student Marks Calculator
Internship: Junior Python Developer Intern
Organization: Yuva Intern
Language: Python 3.13

PROJECT DESCRIPTION:
This project demonstrates debugging and troubleshooting
in a Python student marks calculator.

FEATURES:
1. Accepts student name and marks.
2. Calculates average marks.
3. Assigns grades.
4. Validates numeric input.
5. Handles invalid and empty input.
6. Checks that marks are between 0 and 100.

PROJECT FILES:
- original_buggy_script.py
- corrected_script.py
- debugging_report.docx

HOW TO RUN:
1. Install Python 3.13.
2. Open Python IDLE.
3. Open corrected_script.py.
4. Press F5 to run the program.
5. Enter student name and marks.

EXPECTED OUTPUT:
Student Name: Kavana
Average Marks: 80.0
Grade: B

NOTE:
The original buggy script was created as a demonstration
because the original internship starter file was unavailable.
